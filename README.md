# Azur Promilia Localizations

This repository is for maintaining community-made translations for Azur Promilia, based of the original Japanese text. Only translated text is provided here.
Currently, all translations are made by AI. I plan to do a human review over things once I have some time, going by priorities (UI stuff first, story dialogue later etc)

## Contributing

Anyone is welcome to edit the JSON and open a PR to contribute to improving the translations. You may also ping `seelepeeku` in the ap-translation-help channel in the community discord so I can directly address issues. 
Only requirement is that you actually be knowledgeable in Japanese. This is already made by AI; we kind of don't really need more machine translation passes.

I also welcome anyone who would like to be an actual maintainer; again, know the language though.
